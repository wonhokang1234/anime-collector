# Project Context

This project already has a working frontend.

The goal is to completely revamp and refactor the frontend so it feels:
- creative
- interactive
- premium
- professional
- polished
- intentionally designed
- maintainable

The goal is not a small style cleanup. The goal is a full frontend visual and structural revamp while preserving the existing app behavior.

## Highest Priority

Preserve existing functionality.

Do not break:
- routes
- API calls
- forms
- state management
- authentication/session behavior if present
- modals
- buttons
- user flows
- loading/error behavior
- business logic

## Frontend Revamp Principles

1. Understand the current frontend before changing code.
2. Separate presentation/UI from business logic where possible.
3. Refactor toward reusable components.
4. Build a design system before doing large visual edits.
5. Use animation intentionally, not randomly.
6. Keep the frontend responsive and mobile-friendly.
7. Preserve accessibility basics.
8. Keep changes incremental and reviewable.
9. Run available checks after implementation.
10. Do not add unnecessary dependencies.

## Desired Frontend Feel

The finished frontend should feel like a real product team spent time on it:
- strong visual hierarchy
- clean layout
- premium spacing
- consistent typography
- deliberate color system
- tasteful motion
- polished hover/focus/pressed states
- good mobile behavior
- designed empty/loading/error states
- reusable components
- professional code structure

## Preferred Workflow

Use the manual multi-agent revamp workflow:

1. Audit current frontend.
2. Research product-specific design inspiration.
3. Define new visual direction.
4. Define motion direction.
5. Create component refactor plan.
6. Create phased implementation plan.
7. Implement one phase at a time.
8. Run regression review.
9. Run frontend QA.

Do not jump straight into implementation unless explicitly asked.
